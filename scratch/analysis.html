Analysis limitations

This analysis uses only the four measured parameters: pH, TDS (dissolved solids), turbidity and temperature.

It does not measure, and therefore cannot assess: dissolved oxygen, DO, BOD, COD, hardness, alkalinity, nitrate, phosphate, heavy metals, chlorine or microbial quality.

Application predictions are screening estimates based on the measured parameters only.
